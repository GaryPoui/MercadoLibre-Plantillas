# Archivos de referencia

Guardar los Excel originales y sus informes privados en `data/private/`.
Esa carpeta está excluida de Git, excepto su archivo de estructura `.gitkeep`.
La exclusión de Git evita versionarlos; no cifra los archivos ni controla acceso al equipo.

Se recibió una referencia Google Sheets; se guardaron snapshots API y un informe en
`data/private/`, junto con metadatos y un manifiesto de huellas locales. No son archivos
Excel originales ni copias íntegras de todas las propiedades del libro. Las futuras listas
originales deben conservarse intactas. Si se necesitan ejemplos para pruebas, crear muestras anonimizadas
en una carpeta independiente y documentar qué representan.
